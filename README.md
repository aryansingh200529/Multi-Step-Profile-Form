# React Native Multi-Step Profile Form

A React Native application using TypeScript and Redux Toolkit to manage user profiles via a multi-step form wizard.

## Features
- **3-Step Form**: Basic Info -> Address -> Summary.
- **State Management**: Redux Toolkit for global state and draft handling.
- **CRUD**: Create, Read, Update, and Delete profiles.
- **Validation**: Prevents empty fields.
- **Async Simulation**: Mock API delay when saving.

## Tech Stack
- React Native (CLI)
- TypeScript
- Redux Toolkit
- React Navigation
